WhatsApp Drive Bot
A Flask-based bot that integrates WhatsApp with Google Drive for automatic file management.

Features
Web-based control panel

Real-time status monitoring

Start/Stop functionality

QR code authentication

Google Drive integration

Installation
bash
git clone https://github.com/KeerthanaMaiya/whatsapp-drive-bot.git
cd whatsapp-drive-bot
pip install -r requirements.txt
python whatsapp_drive_bot.py
Access at:  http://127.0.0.1:5000

Usage
Start the bot

Get QR code

Scan with WhatsApp

Send files to automatically save to Google Drive

Project Structure
whatsapp_drive_bot.py - Main application

requirements.txt - Dependencies

templates/ - Web interface

google-auth/ - Authentication files
